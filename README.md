# USO 손목 DICOM 측정기

척골 단축 절골술(USO) 연구용 방사선 계측 웹앱입니다. https://minbom.github.io/uso_wrist/

- DICOM 파일은 브라우저 안에서만 읽습니다. 서버로 업로드하지 않습니다.
- 측정 기록은 브라우저 localStorage에 저장됩니다. 측정자별 CSV(`측정자_YYYYMMDD.csv`)로 내보냅니다. 영상 1장(측정자+회차+파일+측)이 1줄입니다.
- 📁 폴더로 열면 선택한 폴더 이름이 환자명 칸에 자동으로 들어갑니다(폴더 이름 = 환자명). 이미 다른 환자명으로 저장된 영상이면 바꾸지 않고 알립니다.
- 지원 형식: 비압축 DICOM(Explicit/Implicit VR Little Endian). 압축 DICOM은 아직 지원하지 않습니다.

## 측정 변수
| # | 변수 | 도구 |
|---|---|---|
| 1 | Ulnar variance | 1번 점(요골 근위부) 기준 장축 방향 거리: 척골 최원위부(4번)가 요골 척측 모서리(3번)보다 길면 +, 짧으면 − |
| 2 | 절골 각도 | 두 선 각도, 값 = \|90° − θ\| |
| 3 | Callus Index b/a | 척골 척측 가장자리 2점으로 기준선 → b(요측 가골 최대점~선) / a(요측 정상 피질~선) |
| 4 | 절골면 최대 간극 | 점-선 거리: 근위 절골면 2점으로 직선 → 원위 절골면 점(간극 최대 지점)까지의 수직 거리 |
| 5 | 절골부 위치 (원위단~절골선) | 점-선 거리. 6번을 잰 forearm 영상에서 함께 재는 것을 권장 (배율 상쇄) |
| 6 | 척골 전체 길이 (% 계산용, forearm 영상) | 길이. 구상돌기 끝 ~ 원위 척골 끝. 절골 위치(%) 파악용(단축량은 UV로 평가). 같은 영상에 5번이 있으면 그 영상 값으로 % 계산(권장). 없으면 5번 값을 같은 측정자·회차·환자·측의 술후 척골 길이 중 촬영일이 가장 가까운 것과 짝지어 계산 (수술일 칸 필요). CSV `6.% 계산 방식` 열에 어느 방식인지 표시 |
| 8 | 금속판 위치 | 범주 |
| 8-1 | 금속판 홀 개수 | 정수 직접 입력 (0–30) |
| 8-2 | 사용된 나사 개수 | 정수 직접 입력 (0–30) |
| 9 | 나사-절골면 거리 | 점-선 거리 |
| 10 | Wire bone hole-절골면 거리 | 점-선 거리 |
| 11 | 절골 정합도 | 범주 |
| 12 | 유합 상태 | 범주 |
| 부가 | 금속판 제거 (Y/N, 이유) | 범주 |

모든 항목의 기본값은 N/A입니다. 값을 입력한 항목만 바뀌고, 값을 지우려면 N/A 버튼을 누릅니다. 12번 피질 표는 view마다 기본값이 "view 없음"입니다. 관찰 피질 수를 고르고 연결 피질 수를 비워 둔 채 다른 영상으로 넘어가면 경고합니다.
